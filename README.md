📘 Flippix

Flippix is a lightweight study companion where users can create and review flashcard-style decks. The app focuses on improving recall through progressive difficulty and helpful hints that assist learning without giving away full answers.
✨ Key Features
🔹 Deck-Based Learning
- Organize study materials into decks for focused review.
🔹 Hints for Guided Recall
- Each card offers optional hints to support learning without revealing the full answer.
🔹 Difficulty Levels
- Easy
- Medium
- Hard
- Helps track progress and focus on the items that need more practice.
🔹 Progress Tracking
- See how much you’ve reviewed and which cards need more attention.
🔹 Clean, Minimal UI
- Straightforward interface designed for smooth studying.
  
📂 Tech Stack
HTML, CSS, JavaScript
MySQL
